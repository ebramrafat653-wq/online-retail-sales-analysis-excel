Online Retail Sales Analysis (Excel)

Project Overview

This project presents an end-to-end sales performance analysis using Microsoft Excel and Power Query. The objective is to transform raw transactional data into meaningful business insights through a structured analytics workflow, following industry best practices.

The project covers data understanding, data quality assessment, data cleaning, exploratory data analysis (EDA), KPI development, and business reporting.

Project Status: 🚧 Work in Progress

---

Business Problem

The company wants to understand its sales performance between December 2010 and December 2011 in order to:

- Understand sales trends over time.
- Analyze customer purchasing behavior.
- Identify top and underperforming products.
- Evaluate country-level sales performance.
- Detect returns and cancelled transactions.
- Support better business decisions through data.

---

Project Objectives

- Analyze overall sales performance.
- Measure month-over-month revenue growth.
- Identify top-performing products and customers.
- Analyze sales by country.
- Evaluate returns and cancelled orders.
- Detect seasonal sales patterns.
- Build a professional business analysis using Excel.
